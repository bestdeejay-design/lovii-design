# 04 · Отступы, форма, движение, иконки

> Каркас системы — мобильная капсула 480px, разворачивающаяся на планшете/десктопе. Геометрия держится на пилюлях (999px) и карточках 16px. Движение — быстрое на hover, мягкое на вход, отключаемое при reduce-motion.

## Отступы и каркас

| Токен | Значение | Правило |
|---|---|---|
| `--lv-pad-x` | 16px | Боковой отступ любого экрана/секции. Константа, не варьируется |
| `--lv-section-top` (в коде `.section`) | 20px | Отступ секции сверху; блок↔блок = 24px (20 + 4 хвост контента) |
| head-gap | 12px | Заголовок секции ↔ контент (каталог — 16px) |
| gap-шкала | 4·6·8·10·12·14·16px | Гэпы флексов/гридов; шаг не геометрический — по канону |
| card-pad | 12px | Компакт-карточки (store/prod/avail); promo/sum/order — 16px; премиум — 20px |
| `--lv-container` | 480px | Капсула приложения; тень `--lv-shadow-app`; ≥640px — 100% |
| `--lv-container-wide` | 1120px | Общий поток ≥640px |
| `--lv-container-narrow` | 760px | Линейные экраны: товар, поиск, корзина, заказы, профиль, чат |
| `--lv-header-h` / subheader / nav | 56 / 48 / 64px | Sticky-шапки; nav ≥900px — плавающая капсула 60px + padding-bottom 96px у view |
| safe-area | env(safe-area-inset-bottom) | Навигация и чат-инпут; `viewport-fit=cover` обязателен |

Липкие слои (z-index): subheader/поиск 25–30 · хедер 40 · навигация 40 · оверлей 50 · шит 51 · тосты 60.

| Токен | Значение | Применение |
|---|---|---|

| sheet | 24px | Bottom-sheet (верхние углы), премиум-обложки (pd-cover, loyalty, prof-head) |
| premium | 20px | apply-head, roi-card |
| card | **16px** | Все карточки, тосты, строки-выборы |

| msg-tail | 6px | Один угол сообщения чата (остальные 16px) |

## Тени

| Токен | Значение | Применение |
|---|---|---|
| `--lv-shadow-soft` | `0 1px 3px rgba(26,26,26,.06)` | Покой карточек |
| `--lv-shadow-lift` | `0 12px 32px -12px rgba(201,42,106,.22)` | Hover карточек, активные чипы/табы |
| `--lv-shadow-nav` | `0 12px 32px -12px rgba(26,26,26,.28)` | Десктоп-капсула навигации |
| `--lv-shadow-stuck` | `0 12px 16px -16px rgba(26,26,26,.28)` | Липкая плашка чипов (только в stuck) |
| `--lv-shadow-toast` | `0 12px 32px -12px rgba(201,42,106,.35)` | Тосты, fin-total |
| `--lv-shadow-float` | `0 2px 8px rgba(26,26,26,.1)` | Плавающие кнопки поверх обложек |
| `--lv-shadow-app` | `0 0 60px rgba(26,26,26,.08)` | Мобильная капсула |
| `--lv-ring-search` / `--lv-ring-field` | `0 0 0 2px rgba(246,74,138,.4)` / `0 0 0 4px rgba(246,74,138,.1)` | Фокус поиска / форм |

Правило: у карточки всегда либо soft (покой), либо lift (интерактив). Тень не мигрирует «просто так» — она всегда сигнал интерактивности.

## Движение

| Случай | Значение |
|---|---|
| Hover-переходы (color/background/all) | 0.2s |
| Нажатие-трансформ (scale) | 0.15s; масштаб: чипы .96, cta .95, quick .97 |
| Вход контента `.lv-enter` | 0.35s ease-out, translateY(10px)→0; каскад шагом 0.06s (стадии 1–4 в lovii-site) |
| Bottom-sheet | 0.3s cubic-bezier(.32,.72,0,1) |
| Оверлей/тост | 0.25s |
| Сворачивание hero | grid-template-rows 1fr↔0fr, 0.32s; ярлык — padding 0.3s |
| Парение декора `.lv-float` | 5s ease-in-out infinite, амплитуда 8px |
| Пульс точки `.lv-dot` | 1.4s ease-in-out infinite (opacity 1→.45, scale 1→.8) |
| **prefers-reduced-motion** | **обязательно отключить все анимации** |

## Иконки и эмодзи

- Стиль: Lucide — `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`, `stroke-width="2"`, round caps/joins. `aria-hidden="true"`, смысловая кнопка имеет `aria-label`.
- Размеры: 12–14px внутри плашек · 16px стандарт · 18–20px кнопки · 22px навигация.
- Цвет: `currentColor`; брендовая иконка — `--lv-pink`; на soft-плашке — парный `*-text`.
- Эмодзи — контентные образы (товары, точки, категории): 36px карточки · 60–72px обложки · 40–46px empty. Эмодзи не заменяют функциональные иконки.

## Брейкпоинты

| Диапазон | Поведение |
|---|---|
| base <640px | Капсула 480px, товары 2 колонки |
| ≤400px (≤360px) | Сжатие пилюли района (chev скрыт, label 64px; лого 28px) |
| ≥640px | Full width, товары 3 колонки, hero h1 32px, hero-grid 2 колонки (ярлык+поиск в ряд) |
| ≥900px | Навигация — плавающая капсула снизу, view padding-bottom 96px |
| ≥1024px | Товары 4 колонки |

## Do

- Боковой отступ всегда 16px; липкие плашки — без отрицательных отступов.
- Скролл-ленты: `mask-image` канон (`--lv-edge-fade`) — карточки растворяются у краёв.
- Горизонтальный скролл — `no-scrollbar` (скрытый скроллбар).

## Don't

- ❌ Не вводить новые радиусы (0–8px острые углы запрещены).
- ❌ Не делать новые тени/длительности — сначала токен.
- ❌ Не ставить sticky-элементы с отрицательными margin (ломает капсулу).
- ❌ Не анимировать layout-свойства (width/height) — только transform/opacity/grid-template-rows.

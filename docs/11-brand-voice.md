## 1. Голос «Лови» — пять принципов

Голос бренда один для всех продуктов и ролей. Меняется **тон** под ситуацию (§2), а не голос. Каждый принцип — с живой парой «пишем / не пишем».

### 1.1 По-человечески, на «ты»

Один пользователь, тёплый разговорный тон, без канцелярита и «уважаемых». Обращение на «ты» — везде, кроме юридических текстов (§6).

| Пишем | Не пишем |
|---|---|
| «Покажем точки рядом с тобой» | «Уважаемый пользователь! Вам доступны точки» |
| «Выбери район — и мы всё покажем» | «Осуществите выбор района для отображения» |

### 1.2 Короче — лучше

Одна мысль — одна строка. Заголовок экрана — до 30 знаков, тело — до 80, тост — одна строка + необязательная подпись (канон docs/07 §10). Если не влезает — режем суть, а не уменьшаем шрифт.

| Пишем | Не пишем |
|---|---|
| «Добавили в корзину» | «Товар успешно добавлен в вашу корзину покупок» |
| «Нет сети. Покажем сохранённое» | «К сожалению, в данный момент отсутствует подключение» |

### 1.3 Глаголы действия

Кнопка и заголовок говорят, что произойдёт. Пассивные конструкции и «здесь можно…» — запрещены.

| Пишем | Не пишем |
|---|---|
| «Скопировать ссылку» | «Здесь вы можете скопировать ссылку» |
| «Выбери район» | «Район должен быть выбран» |

### 1.4 Конкретика вместо оценок

Цифры и факты вместо «рядом», «скоро», «много». Канон витрины: расстояние — в минутах пешком, время — «до ЧЧ:ММ», количество — точным числом.

| Пишем | Не пишем |
|---|---|
| «7 минут пешком · до 18:00» | «Рядом с вами · работает допоздна» |
| «24 точки в районе» | «Много точек поблизости» |

### 1.5 Без вины пользователя

Ошибка = что случилось + что делать. Никаких восклицаний, капса и обвинений. Системные коды и технический жаргон — только в логи, не в интерфейс.

| Пишем | Не пишем |
|---|---|
| «Не получилось. Проверь номер — нужно 11 цифр» | «Ты ввёл неверные данные!» |
| «Нет сети. Покажем сохранённое» | «ОШИБКА: ECONNREFUSED. Повторите попытку позже» |

## 2. Матрица тона: ситуация → как звучим

Голос один, тон — пять режимов. Полные живые демо — `examples/07-voice-lab.html` §2.

| Ситуация | Тон | Канонический текст (Do) | Запрещено (Don't) |
|---|---|---|---|
| Успех | тёплый, короткий | «Добавили в корзину» + подпись «Молочная лавка · самовывоз через 15 минут» | «Ура!!! Товар твой!» (восторги, многократные «!») |
| Ошибка / нет сети | спокойный, помогающий | «Нет сети» + «Покажем сохранённое» | капс, коды ошибок, «Повторите попытку позже» без альтернативы |
| Пустое состояние | дружелюбный + действие | «Здесь пока пусто» + «Загляни через пару минут — витрина пополняется» + кнопка | голое «Список пуст», извинения «Приносим извинения за…» |
| Загрузка | честная, краткая | «Загружаем витрину…» | «Пожалуйста, подождите, идёт обработка вашего запроса» |
| Деньги, выплаты | точный, без шуток | «Выплата придёт до 5 числа» | уменьшительные («денежка»), смайлы, обещания «мгновенно» без гарантии |

**Правило одного восклицания:** на экране — не более одного «!». В тостах об ошибке и деньгах — ноль.

## 3. Правила письма

### 3.1 Название бренда

- В русском тексте — **«Лови»** в кавычках-ёлочках: «приложение „Лови“» → проще: приложение «Лови».
- Латиницей **LOVII** — только в логотипе, заголовках бренд-страниц и доменах.
- Не склонировать: «в приложении «Лови»», не «в Лови» / «в Ловии».

### 3.2 Кнопки

- Глагол или глагол + объект: «Добавить», «Оформить заказ», «Скопировать ссылку».
- Без точки в конце. До 18 знаков для primary 36px (канон docs/09).
- Не «ОК», не «Да/Нет» — всегда конкретное действие.

### 3.3 Заголовки и регистр

- Sentence case: «Акции рядом», не «Акции Рядом» и не «АКЦИИ РЯДОМ».
- КАПС разрешён только в кикерах (10.5px caps — канон типографики).
- Без точки в конце заголовка.

### 3.4 Пунктуация

- Многоточие — символ «…», не три точки: «Загружаем…».
- Восклицательный знак — по правилу §2 (≤1 на экран).
- Тире — среднее «–» в диапазонах (640–899) и длинное «—» в предложениях.
- Эмоджи запрещены всегда (AGENTS пр.11) — эмоцию даёт тон и SVG-иконка.

### 3.5 Числа, время, деньги

- Метрики — табличные цифры: `font-variant-numeric: tabular-nums` (канон KPI).
- Время: «до 18:00», формат ЧЧ:ММ, без «часов»/«o'clock».
- Дата в UI: «4 сентября»; в юр.текстах — «04.09.2026».
- Деньги: «249 ₽», пробел между числом и ₽; старая цена — зачёркнутая пара (канон price).
- Расстояние: в минутах пешком — «7 мин пешком» (канон walk-pill).
- Проценты: «до 15%», без пробела.

## 4. Словарь

Термины канона. Правая колонка — не орфографическая ошибка, а **чужое слово**: оно уводит от канона витрины.

| Пишем | Не пишем | Почему |
|---|---|---|
| точка | магазин, филиал, заведение | канон витрины: «24 точки в районе» |
| витрина | каталог, главная страница | главный экран клиента |
| самовывоз | пикап, забор заказа | без калек |
| корзина | тележка, cart | |
| район | зона, локация | «Выбери район» |
| баланс | кошелёк, счёт | у амбассадора/партнёра |
| выплата | вывод средств | для партнёра и амбассадора |
| амбассадор | посол бренда | имя роли в ДС |
| промокод | купон, ваучер | устоявшийся, разрешён |
| дашборд | панель управления | только в контексте роли «бизнес» |

Англицизмы: только устоявшиеся из таблицы. Если есть русский эквивалент — русский.

## 6. Юридический блок

Единственное место, где голос меняется: **нейтральное изложение, полнота важнее краткости**, но язык — простой, без бюрократических оборотов.

**Где живёт:** подвал (демка, посадка) — hairline сверху, текст `--lv-dim` 12px, ссылки — `pink-dark`. Канон разметки:

```html
<footer class="legal">
  <span>© «Лови», 2026</span>
  <a href="/oferta">Оферта</a>
  <a href="/privacy">Политика конфиденциальности</a>
  <a href="/requisites">Реквизиты</a>
</footer>
```

**Правила:**

- Полные наименования: ООО «…», ИНН, ОГРН — в «Реквизитах», не в футере.
- Даты — полные: «редакция от 04.09.2026».
- Обращение — нейтральное («пользователь»), «ты» только в UI вокруг.
- Маркетинг в юр.текстах запрещён: ни «лучшего», ни «уникального».
- Ссылки открываются в новой вкладке из посадки, в приложении — внутри.

## 7. Иллюстрации и иконки

- **Иконки** — только из `assets/icons.svg` (26 шт., пр.11): 24px сетка, stroke 2, `currentColor`. В empty-состояниях — 36–48px, `--lv-dim`.
- **Маскот** — `i-bear`: дружелюбные сцены (пустые состояния, onboarding, чек-листы). Не используется в ошибках и деньгах — там точность важнее милоты.
- **Кастомный линейный набор** (bear, ring, choco, salad, flower) — фирменная подача категорий; рисовать новые — в том же стиле: 2px, round, без заливок (кроме `i-star` gold).
- **Плитки `tile-*`** — иллюстрация категории по умолчанию; текст на плитках — только пара `on-tile` (v1.1).
- **Фото** — реальные фото точек/продуктов; без стоковых людей и «улыбок с депозитов». Обложка карточки — 120px (канон docs/09).
- **Запрещено:** эмоджи, стоковые коллажи, растровые иллюстрации >100 KB, градиентные «сердечки» вне бренд-градиентов.
- Иллюстрация **не заменяет текст**: empty всегда = иконка + заголовок + тело + кнопка (§5).

## 8. Чек-лист текста

Прогонять перед коммитом любого экрана (дополняет docs/checklist):

- [ ] Обращение на «ты»; нет «Уважаемый пользователь», канцелярита
- [ ] Нет эмоджи, КАПСА (кроме кикеров), ≤1 восклицательного знака на экран
- [ ] Кнопки — глаголы без точки, ≤18 знаков; нет «ОК»/«Да»
- [ ] Ошибка говорит, что случилось и что делать; без вины пользователя
- [ ] Числа конкретные: минуты пешком, «до ЧЧ:ММ», ₽ с пробелом; метрики — tabular-nums
- [ ] Термины из §4; англицизмы только устоявшиеся
- [ ] Заголовки sentence case, без точки
- [ ] Empty = иконка + заголовок + тело + кнопка
- [ ] Юр.блок по §6: нейтральный тон, полные даты, ссылки работают
- [ ] Многоточие «…» символом, тире — «–»/«—», кавычки «ёлочки»

# 13. Сайт продукта и лонгрид

> Канон страниц-документов: сайт lovii.ru, white paper, лендинги продукта.
> Класс артефакта отличается от капсулы приложения (480px), но токены — те же.
> Каждый паттерн здесь — обязанность соблюдать на любом сайте продукта.

## §0. Класс артефакта

Дизайн-система обслуживает два класса артефактов:

| | Капсула приложения (examples/01–08) | Лонгрид / сайт продукта (этот документ) |
|---|---|---|
| Носитель | 320–480px, mobile-first | 360–1280px+, чтение с любого экрана |
| Контейнер | капсула 480px | 820–860px, центр |
| Таблицы | запрещены (docs/12) | разрешены (.data-table §3) |
| Навигация | bottom-nav / капсула | фиксированный хедер + якоря |
| Цель | действие | чтение + решение (инвестор, партнёр) |

Токены, иконки, радиусы, тени, темы, голос — общие (tokens.css, docs/02–05, docs/11).
Паттерны лонгрида не перетекают в капсулу, капсула не перетекает в лонгрид.

## §1. Каркас страницы

1. **Anti-FOUC** — тема до первой отрисовки: инлайн-скрипт в `<head>` ставит `data-theme`
   на `<html>` из localStorage до CSS. Событие `lovii:theme` — канон (docs/05).
2. **Двойной meta theme-color** — `<meta name="theme-color" media="(prefers-color-scheme: light)">`
   + dark-версия; переключается из applyTheme (docs/05).
3. **Шрифт** — Inter как webfont (`preconnect` + `display=swap`), fallback — стек `--lv-font`.
4. **Хедер** — фиксированный, стекло `--lv-glass` + `backdrop-blur`, логотип-пара
   (light/dark, docs/05), якоря секций с состоянием `.active`, гамбургер < 1000px
   (иконка из спрайта, не эмодзи).
5. **Якоря** — `scroll-margin-top: calc(var(--lv-header-h, 64px) + 16px)` на секциях;
   внешний вход по якорю повторяется на `load` (docs/10 §1).
6. **Контейнер** — `.container { max-width: 860px }`, hero — 820px, паддинги 28px
   (16px на < 640px).

## §2. Hero-подпись

Первый экран сайта продукта — визитная карточка бренда. Обязательный набор:

- **Кикер-пилюля** — версия документа / статус («White Paper v2.0», «MVP»):
  `background: color-mix(in srgb, var(--lv-pink) 12%, transparent)`, текст `--lv-pink-dark`
  (в dark — `--lv-pink`), uppercase, letter-spacing 0.04em.
- **H1 с градиентным словом** — фирменный приём: одно слово/оборота в
  `linear-gradient(100deg, var(--lv-pink), var(--lv-tiffany))` + `background-clip: text`.
  Остальной текст — `--lv-ink`.
- **Meta-строка** — дата · статус · юрлицо: 15px `--lv-dim`, разделители «·»,
  на мобиле — перенос в две строки.
- **Ambient-декор** — кольца, свечения, pulse-точки в боковых полях (гуттерах):
  `position: absolute; pointer-events: none;` глубина параллакса `data-depth` (0.4–1.1),
  цвета — бренд-альфы (pink/tiffany ≤ 0.4), `overflow: hidden` на слое.
  Обязательно `display: none` до загрузки CSS-слоя и `@media (prefers-reduced-motion: reduce)`
  — вся анимация декора выключается.
- **Свечение** — радиальный градиент за hero
  (`radial-gradient(ellipse, rgba(246,74,138,.07), transparent 70%)` — light;
  tiffany-альфа — dark).

## §3. Ленточные паттерны

Все значения — через `var(--lv-*)`. Числа — `tabular-nums` (docs/11 §4).

### .toc — содержание
Карта документа: счётчик `counter(toc)` с `--lv-pink`-номерами, ссылки `--lv-ink`,
hover — `--lv-pink`. Заголовок «Содержание» — 14px uppercase `--lv-dim`.

### .highlight — врезка
`border-left: 3px solid var(--lv-pink)`, фон `--lv-surface`, радиус `--lv-r-md`
(справа). Сильный факт/вывод — не более одной на секцию.

### .stats — метрики
Ряд `num + label`: num 32px/800 `--lv-pink` (tabular-nums), label 14px `--lv-dim`.
Максимум 4 метрики в ряду, gap 24/48px.

### .timeline — фазы
Вертикальная линия `--lv-border`, точки 12px `--lv-tiffany` (фаза 1), `--lv-pink`
(фаза 2), `--lv-gold` (фаза 3) — цвет кодирует этап. Шапка фазы — 13px uppercase
соцветом фазы, критерии перехода — `strong` цвета текста.

### .calc — расчётная карта
Строки `label — value` с hairline-разделителями; итоговая строка — верхний бордер
2px `--lv-pink`, value 17px/800 `--lv-pink-dark`. Заголовок карты — 15px/700.

### .data-table — таблица данных
Разрешена только в лонгриде (в капсуле запрещена — docs/12). Первая колонка —
`--lv-ink`/500, прочие `--lv-dim`; hairline-строки; шапка на `--lv-surface`;
горизонтальный скролл обёрткой `.table-wrap` с отрицательными полями на мобиле.

### .tag / .tag-date
Классификатор карточки: пилюля 12px uppercase с бренд-альфой (как кикер) и
дата-пилюля на `--lv-surface-2` с бордером `--lv-border`, tabular-nums.

### .doc-card — карточка контента
`icon (спрайт, 20–24px) + title + body`; фон `--lv-surface`, бордер `--lv-border`,
радиус `--lv-r-md`; hover — `translateY(-3px)` + `--lv-shadow-lift`.

## §4. Декор и движение

### Тихая тёмная тема лонгрида (v1.9, принцип — docs/05)

Светлая тема лонгрида живая и многолосая (кикеры трёх гамм, цветные цифры —
норм). Тёмная — тихая: читатель ночью, один акцент в кадре.

- **Кикеры секций** — нейтральная пилюля: фон `--lv-surface`, текст/иконка `--lv-dim`.
- **Цифры-данные** (`.stat .num`, `.doc-card .value`) — `--lv-ink`, любые модификаторы гасятся.
- **Теги** — нейтральные (как `.tag-date`); **чип-иконка карточки** — единая
  розовая гамма (`--lv-soft-pink` + `--lv-pink`) вместо трёхцветной череды.
- **Hero-градиент** — без циана: `pink → sand` (тёплое шампанское на сливовом).
- **Ambient** — кольца `--lv-hairline`/sand-альфа (без циановых), пульс-точки —
  только розовые, вторые гаммы `display: none`, свечение hero — розовое.
- **Wave** — альфы .05/.04; **подписи фаз таймлайна** — `--lv-dim` (цвет — в точке).
- **Врезка** — рамка розовая, `strong` — чернилами (розовый в тексте не сыплется).

### Движение

- **Wave-полоса** — фирменная SMIL-волна (анимированный path в SVG): градиент
  pink→tiffany→gold, высота 48–90px, между hero и контентом или в футере.
  `aria-hidden="true"`, в print отключается.
- **Reveal-каскад** — `.js section { opacity:0; translateY(24px) }` → `.revealed`
  через IntersectionObserver (threshold 0.2); no-JS fallback — всё видно
  (`<noscript>` + класс `js` на `<html>`); reduce-motion — без анимации (docs/10 §1).
- **Active-nav** — наблюдатель секций подсвечивает якорь текущей секции.
- **Hover-подъём** — карточки/ссылки-карты: −3px + lift-тень, 0.25s ease.

## §5. Иконки

Только спрайт канона (`assets/icons.svg`, 18px stroke): секционные маркеры 20–24px,
иконки в карточках, контакты (i-mail, i-phone), пиктограммы Domу —
по реестру docs/12. Эмодзи запрещены (AGENTS).

## §6. Голос, SEO, печать

- **Голос** — docs/11: на «ты», глаголы действия, конкретика вместо оценок,
  числа пешком, деньги с пробелом и ₽. Маркетинговый слой не искажает факты:
  каждая цифра на сайте подтверждается white paper.
- **SEO-обвязка сайта** (неотменяемый набор): canonical, description, JSON-LD
  Organization (юрлицо, адрес, ИНН, телефон, email), Open Graph + twitter:card,
  geo (регион/город/координаты), sitemap.xml, robots.txt, manifest (bg `#f8f5f0`,
  theme `#f64a8a`).
- **Print** — white paper печатают: хедер/декор/toc/CTA скрываются, фон белый,
  `break-inside: avoid` на карточках/врезках/картах, ссылки подчёркнуты чёрным.

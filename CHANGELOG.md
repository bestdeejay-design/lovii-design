Изменение значений токенов: backward-compatible — MINOR, ломающее — MAJOR, правки правил/опечаток — PATCH.

## [1.7.0] — 2026-09-04

### Added
- **Дизайнерский аудит всего проекта** (запрос владельца: «эстетический взгляд надо усилить… чтобы проект выглядел на старте стильным и максимально был запоминаемым») → волна эстетических усилений.
- **Радиус-токены** `--lv-r-sm/md/lg/xl/pill` (tokens.css + design-tokens.json `$css`-привязки): 182 литерала в 11 файлах переведены на var(); в docs/04 таблица радиусов дополнена именами токенов. Литеральые радиусы в коде ДС больше не встречаются.
- **Favicon** `assets/favicon.svg` (градиентное сердце на брендовой плашке) — подключён на хаб, все 8 примеров и style-guide (через tpl-head).
- **Соцпревью хаба**: og:title/description/image/url + twitter:card, обложка `assets/og-cover.png` 1200×630 (тёмно-сливовый фон, свечение бренда, логотип, чипы палитры); мета description для поиска.
- **Фирменное свечение бренда**: живые радиальные блобы (::before/::after, lv-float, reverse-фаза) на hero хаба и примеров 01/06/07/08, на чернильной статус-карточке 03 — розово-белое дыхание на градиенте, reduce-motion гасится глобально.
- **Каскадный вход секций хаба**: IntersectionObserver + .reveal с каскадной задержкой 70мс, фолбэк без IO, уважение prefers-reduced-motion.
- **`::selection` в каноне** (tokens.css): выделение текста — брендовый розовый с белым текстом; системное синее больше не выбивается из палитры.
- **Кикер-пилюля** — подписной приём бренда (soft-pink капсула uppercase) поднят с гайда на хаб: все 6 секций хаба получили фирменные ярлыки «Гайд/Роли/Паттерны/Тон/Компоненты/Доки».

### Changed
- **Градиентное слово в h1 хаба**: «Лови» — градиент белый → песочный (background-clip:text), приём из KPI/промокода поднят на уровень бренда.
- **Hover-подъём карточек хаба**: guide/role-карточки получают translateY(-2px) + shadow-lift на hover (раньше — только :active-сжатие); тень гайд-карточки в покое смягчена до soft.

### Fixed
- Гигиена кода: удалены копипаст-дубли CSS-правил (index: .theme-btn ×2, .doc-num svg ×2; 01: .theme-btn ×2, .cover .cv-ico ×2, tpl-head: .cover .em ×2 — слиты в один .ico).
- Классы-пережитки эмодзи-эпохи переименованы: `.tile .emoji` → `.tile .ico` (01), `.hero .emoji` → `.hero .ico` (04), `.cover .em` → `.cover .ico` (гайд) — документация больше не разносит мёртвые имена.

## [1.4.1] — 2026-09-04

### Fixed
- **Центр правды восстановлен** (репорт владельца: «в документации один цвет, а сам фон другой»): таблицы свотчей style-guide хранили **копии** значений токенов и дрейфанули при v1.3 — показывали старые `#f7f2f4` / `#f0e8ec` / `#f7f2f5` при каноне `#f8f5f0` / `#ece5da` / `#f6f1e8`. Покрытие таблиц расширено: `--lv-glass`, `--lv-on-brand`, `--lv-mist-pink`.
- Дубли канона в демо-CSS шаблонов заменены на `var()`: `cta-btn`, `glass-demo`, `badge-*`, `open-pill.on`, `cover.tile-*`. Неизбежные пины (`meta theme-color`, подложки лого-дуэта) помечены `TOKEN-PIN`.
- Синхронизированы разъехавшиеся версии: design-tokens.json `$version` 1.3.0 → 1.4.1 (пропущен при 1.4.0), шапка tokens.css, «Semver 1.0.0» → «Версия v1.4.1» в hero гайда, пилюли style-guide и хаба, README.

### Added

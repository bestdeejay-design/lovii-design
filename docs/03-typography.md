# 03 · Типографика

> Единственный шрифт системы — **Inter** (Google Fonts, weights 400–800). Заголовочный вес — 800 (Extra Bold), его использует большинство заголовков системы. Кегль мелкий, плотный, «приложенческий» — без монструозных дисплейных размеров.

## Подключение

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

Стек: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif` — токен `--lv-font`. Body: `-webkit-font-smoothing: antialiased; text-rendering: optimizeLegibility`.

## Веса

| Токен | Вес | Где используется |
|---|---|---|
| regular | 400 | Тело текста, подписи |
| medium | 500 | Пилюли-контролы, подписи навигации |
| semibold | 600 | Чипы, stat-pill, ссылки, подписи строк |
| bold | 700 | Имена, кнопки, значения, подзаголовки 16px |
| extrabold | 800 | **Все h1/h2, цены, KPI** — заголовочный вес системы |

## Интерлиньяж и трекинг

- lh: hero 1.22 · заголовки/имена 1.3–1.35 · тело **1.6** (обязателен для абзацев и lead).
- tracking: −0.01em крупные h1, −0.02em KPI/лого/цифры 26px, +0.06…+0.12em только для UPPERCASE-бейджей и kicker'ов.
- Обрезка длинных строк: `white-space: nowrap + text-overflow: ellipsis` — одна строка; `-webkit-line-clamp: 2` — имена товаров. Никогда не обрезать заголовки h1.

## Do

- Заголовок = weight 800. Любой текст на soft-плашке = 600–800.
- Lead-абзацы: 14px, lh 1.6, `--lv-dim`; акцент внутри — `<b>` = `--lv-ink`/600.
- Числительные (цены, суммы, KPI) — 800 с отрицательным трекингом.
- На градиентных карточках текст `rgba(255,255,255,.7)` для описаний — канон (loyalty, roi-card).

## Don't

- ❌ Не вводить другие шрифты (даже системные «для красоты») и курсив.
- ❌ Не использовать weight 900 / 300 — их нет в подключении.
- ❌ Не увеличивать h1-hero за пределы 26/32px и не делать текст правее канонных уровней.
- ❌ Не делать основной текст светлее/темнее токенов ink/dim.
- ❌ UPPERCASE без letter-spacing запрещён (кроме икон-текста эмодзи).

## Чек-лист раздела

- [ ] Inter подключен с preconnect и display=swap, веса 400–800
- [ ] Заголовки — 800, текст — из шкалы размеров, без промежуточных значений
- [ ] Абзацы имеют lh 1.6; длинные строки обрезаны по канону
- [ ] Kicker'ы — uppercase с трекингом ≥0.06em

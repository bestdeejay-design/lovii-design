# 02 · Цвет

> Палитра построена на трёх акцентах — розовый (primary), тиффани (secondary), золото (tertiary) — на тёплой нейтральной базе. У каждой темы своя палитра поверхностей; акценты в темах не меняются.

## Брендовые акценты (не зависят от темы)

| Токен | Значение | Роль |
|---|---|---|
| `--lv-pink` | `#f64a8a` | Primary. CTA, активные состояния, ссылки, фокус, брендовые иконки |
| `--lv-pink-dark` | `#c92a6a` | Hover CTA, конец градиента, текст на soft-pink |
| `--lv-tiffany` | `#0abab5` | Secondary. «Пешком рядом», «в наличии», успех |
| `--lv-gold` | `#d4a854` | Tertiary. Премиум, лояльность, рейтинг |
| `--lv-sand` | `#e8d5b7` | Тёплый песочный — бордеры/текст золотой группы |
| `--lv-on-brand` | `#ffffff` | Текст/иконки **на** брендовом градиенте |

## Градиенты

- `--lv-gradient-brand` = `linear-gradient(135deg, #f64a8a 0%, #c92a6a 100%)` — CTA, активные чипы, бейджи, итоговые плашки. Угол **всегда 135deg** (или 90deg в горизонтальных прогресс-барах).
- `--lv-gradient-ink` = `linear-gradient(150deg, #262023 0%, #1a1a1a 55%, #2b1219 100%)` — премиум-карточки (лояльность, профиль). Угол **всегда 150deg**.
- `--lv-gradient-tiffany` / `--lv-gradient-gold` — заливки прогресс-баров (90deg).
- Подложки-плитки категорий: `--lv-tile-pink|tiffany|gold|sand|ink` — всегда 135deg, только светлая подача (в тёмной теме допустимо приглушать opacity обёртки, но не менять цвета плитки).
- **Текст и чипы НА плитках** — только фиксированные токены (введены в v1.1.0): `--lv-on-tile #1a1a1a` (основной), `--lv-on-tile-dim #8a7a84` (вторичный), `--lv-tile-chip rgba(26,26,26,.07)` (нейтральный чип на плитке). Темовые `--lv-ink`/`--lv-dim` на плитках запрещены: в тёмной теме они становятся светлыми и растворяются на светлом фоне плитки.

## Правило soft-пар

Soft-заливка никогда не используется с сырым акцентом или произвольным текстом. Только парой:

- `--lv-soft-pink` → текст `--lv-pink-dark` (не `--lv-pink`: на заливке он недостаточно контрастен)
- `--lv-soft-tiffany` → текст `--lv-tiffany-text`
- `--lv-soft-gold` → текст `--lv-gold-text`
- `--lv-grey-soft` → текст `#999999` (единственный канон-литерал выключенного состояния)
- `--lv-green-soft` → текст `--lv-green-text`

## Do

- Использовать `var(--lv-*)` для любого цвета в коде.
- Текст на брендовом/чернильном градиенте — только `--lv-on-brand`.
- Иконки окрашивать `currentColor`, задавая цвет у родителя.
- Нейтральные статусы — `--lv-grey-soft` + `#999`; успех/наличие — tiffany-пара.
- Проверять оба экрана: решение по цвету принимается сразу для light и dark.

## Don't

- ❌ Не хардкодить `#f64a8a` и прочие значения в компонентах.
- ❌ Не менять брендовые pink/tiffany/gold между темами.
- ❌ Не использовать `#000`/`#fff` для текста и поверхностей (исключение — `--lv-on-brand` на градиенте).
- ❌ Не смешивать soft-заливку одного тона с текстом другого (`soft-gold` + `tiffany-text` запрещено).
- ❌ Не invent-ить новые прозрачности (`.18`, `.35`) без внесения токена в lovii-design.
- ❌ Не использовать чистый тиффани/золото как цвет текста на белом/карточке — только их `*-text` версии.

## Чек-лист раздела

- [ ] Каждый цвет в коде — через токен
- [ ] Soft-заливки использованы в паре со своим `*-text`
- [ ] Обе темы проверены, чистых #000/#fff в тексте нет
- [ ] Градиенты имеют канонные углы (135/150deg)

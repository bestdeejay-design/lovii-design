# LOVII · канон иконок

**Статус:** 🟧 черновик канона (SZ-062, вариант A) · **Источник:** lucide-static v1.47.0 (ISC)
**Задача:** перенести иконки витрины в канон дизайн-системы; дать единый реестр и витрину для подбора.

## Состав

| Файл | Что |
|---|---|
| `sprite.svg` | Единый SVG-спрайт: **1848 иконок** (lucide), контур 24×24, `currentColor` |
| `icons.registry.json` | Реестр: `id → разметка иконки` (для генерации снапшотов в потребители) |
| `catalog.html` | Витрина-каталог с поиском и копированием имени (подключение через `<use href="sprite.svg#id">`) |

## Правила (черновик)

1. **Цвет** — только `currentColor`; размер — снаружи (класс/токен), не в разметке иконки.
2. **Размер** — по шкале ДС (см. `../tokens/tokens.css`, `--lv-icon-*`); явный класс у каждого использования.
3. **Именование** — как в lucide (`kebab-case`), без префиксов.
4. **Витрина `demo`** не инлайнит весь каталог: из реестра генерируется **снапшот только используемых** иконок (иконки-в-каталоге ≠ иконки-в-клиенте).
5. **Правки** — только здесь; потребители получают снапшот (по образцу токенов, `tools/propagate.py`).

## Шкала размеров (утверждено владельцем 2026-09-20)

`16 / 18 / 20 / 24 / 32` px — сохраняет текущее визуальное состояние (базовые 16 и 18).
Токены: `--lv-icon-16`, `--lv-icon-18`, `--lv-icon-20`, `--lv-icon-24`, `--lv-icon-32` (Гейт №2).

## Предпросмотр перед внесением

`catalog.html` — витрина-предпросмотр: клик по иконке открывает попап с ней
в шкале размеров и **на стандартных местах интерфейса** (кнопка действия, иконочная
кнопка, нижняя навигация, строка списка, чип-фильтр, поле ввода) с переключением размера.
Назначение — визуально проверить, как иконка сядет в реальный интерфейс, до правок кода.

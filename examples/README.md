# Примеры экранов LOVII по ролям

Готовые референс-страницы: как дизайн-система собирается в цельные экраны для каждой клиентской роли. Все значения — только из `../tokens/tokens.css` (подключается через `<link>` — примеры всегда тянут актуальный канон).

Каждый пример:
- подключает `tokens.css` и шрифт Inter 400–800;
- содержит anti-FOUC инлайн-скрипт **до** CSS, канонический `applyTheme`, переключатель темы;
- использует оба логотипа в DOM с CSS-переключением (`logo-light-img` / `logo-dark-img`);
- собран на капсуле 480px с брейкпоинтами 640/900/1024;
- проходит чек-лист `docs/checklist.md`.

## Правила использования примеров

1. **Копируй механику, а не значения**: классы могут переименовываться под проект, но токены, пары `soft→*-text`, радиусы, отступы и тайминги — неизменны.
2. **Проверяй обе темы** после любых правок (переключатель в хедере каждого примера).
3. **Новые компоненты** сначала добавь в `docs/07-patterns.md` (сниппет) и при необходимости в style-guide, затем используй.
4. Примеры — справочные, не прод: их не деплоят, но их код должен проходить `docs/checklist.md`.

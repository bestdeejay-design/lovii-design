# Чек-лист приёмки вёрстки LOVII

> Финальный фильтр перед коммитом/деплоем любого клиентского экрана. Применяется к lovii_demo, lovii-site и будущим продовым проектам. Скриншот-проверка — в style-guide.html (обе темы).

## 1. Токены

- [ ] В файле нет хардкода цветов/теней/радиусов вне tokens.css (grep по `#[0-9a-fA-F]{3,8}` вне токен-файла — только объяснённые канон-литералы: `#999` выключенный, badge-подложки)
- [ ] Все новые значения внесены в lovii-design (tokens.css + design-tokens.json) до использования
- [ ] Маппинг имён соответствует docs/06 (нет дублей-синонимов)

## 2. Темы

- [ ] Anti-FOUC инлайн-скрипт в head до CSS; try/catch вокруг localStorage
- [ ] Переключение: луна/солнце, оба логотипа в DOM, видимость через CSS
- [ ] meta theme-color обновляется (light #f64a8a / dark #171219)
- [ ] color-scheme задан; тёмная тема — сливочная палитра, без чистых #000/#fff
- [ ] Проверены: холодный старт обеих тем, системная тема, приватный режим

## 3. Цвет и контраст

- [ ] Soft-заливки в паре со своими `*-text`; grey-soft → #999
- [ ] Текст на градиентах — только on-brand (или rgba(255,255,255,.65–.7) для вторичного)
- [ ] Брендовые акценты не меняются между темами
- [ ] Градиенты: 135deg брендовый, 150deg чернильный

## 4. Типографика

- [ ] Inter 400–800 подключен (preconnect + display=swap)
- [ ] Заголовки 800; размеры из шкалы (26/20/18/16/14/13/12/11/10)
- [ ] Абзацы lh 1.6; обрезки по канону (nowrap+ellipsis / line-clamp 2)
- [ ] Uppercase-текст имеет letter-spacing ≥0.06em

## 5. Геометрия и отступы

- [ ] Боковой отступ 16px; секция 20px; заголовок↔контент 12px
- [ ] Радиусы из шкалы (999/24/20/16/14/12/6); контролы — пилюли
- [ ] Тени: soft в покое, lift на hover; других нет
- [ ] Sticky-слои без отрицательных отступов; z-index 25–60 по канону
- [ ] Safe-area (env(safe-area-inset-bottom)) на нижних барах; viewport-fit=cover

## 6. Движение

- [ ] Hover 0.2s, нажатия 0.15s (scale .95–.97), вход .35s
- [ ] Bottom-sheet cubic-bezier(.32,.72,0,1)
- [ ] prefers-reduced-motion отключает анимации
- [ ] Анимируются только transform/opacity (и grid-template-rows для сворачиваний)

## 7. Адаптив

- [ ] 375px: капсула/отступы, лого 28px ≤360px, нет горизонтального скролла
- [ ] 640–900px: full width, сетки 3 колонки, hero 32px
- [ ] ≥900px: плавающая капсула навигации, view padding-bottom 96px
- [ ] Карточные ленты с edge-fade маской

## 8. Доступность

- [ ] :focus-visible розовый (2px, offset 2px); форм-поля ring-field
- [ ] aria-label у иконочных кнопок; aria-hidden у декоративных SVG
- [ ] Цели касания ≥36px
- [ ] Контраст: dim-текст читаем на card; *-text читаем на своей soft

## 9. Интеграция и релиз (для демки)

- [ ] `css/lovii.css?v=N` и `sw.js CACHE lovii-vN` подняты
- [ ] Логи Actions чистые; прод проверен живьём (обе темы, мобильный вьюпорт)
- [ ] Обновлена запись в worklog; изменения стилей отражены в lovii-design (если менялись значения)

## 10. Документация

- [ ] Новый паттерн/компонент описан в lovii-design (docs или style-guide)
- [ ] Таблица расхождений docs/06 актуальна

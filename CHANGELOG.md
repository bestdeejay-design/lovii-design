## [1.13.3] — 2026-09-12

### Fixed
- **Правая колонка профиля LOVII PAY — выравнивание и наезды (§10, синхронно с демо; фидбек владельца):**
  - **Сдвиг карточки истории:** `.tx-list` в колонке держал мобильные боковые `margin: 0 16px` — список съезжал на 16px вправо относительно своего заголовка, табов и `.tier-card` (кромки 363/748 → 379/733 при 768px). Сброс боковых margin добавлен: `.pay-cols .acct-card, .pay-cols .tier-card, .pay-cols .tx-list`.
  - **Табы фильтров в узкой колонке (641–791px):** `flex:1` без `white-space: nowrap` — «Начисления» держал min-content, остальные сжимались, «Списания» обрезался за кромкой колонки (переполнение ~18px). Теперь табы `nowrap`, 11.5px, паддинг 7×8, gap 4 — все четыре помещаются даже в колонку 320px, без обрезки.
  - **Лесенка подсказок под картой** (узкая колонка): подписи переносились внутри себя на 2 строки вразнобой. `.pay-hints` получил `flex-wrap: wrap; row-gap: 4px`, подписям `white-space: nowrap` — переносятся целыми строками.
  - **Верхняя кромка правой колонки:** первый заголовок («История операций») стартовал на 8px ниже карты левой колонки — `.pay-cols .pay-col-b > .section-head:first-child { margin-top: 14px }` выравнивает по кромке `.pay-stage`.

## [1.13.2] — 2026-09-12

### Added
- **Адаптив профиля LOVII PAY (§10 + docs/09 §8):** двухколоночная композиция «как в веб-банке» от **≥640px** — обёртка `.pay-cols` (grid 5fr/6fr, gap 22→28px от 1024px): слева `.pay-col-a` — карта + счёт (sticky top 68px при высоте окна ≥660px), справа `.pay-col-b` — история + статус. На мобильном (<640px) колонки стекаются в прежнем порядке секций (карта → счёт → история → статус) — разметка демо не меняла порядок. Витрина привилегий от ≥640px — сеткой `auto-fit minmax(200px,1fr)` вместо горизонтальной ленты; подсказки под картой в колонке — компактные (10.5px, одна строка). Причина: на десктопе 3D-карта тянулась на всю колонку 760px (~730px шириной) — фикс фидбека владельца «карта великовата на вебе».
- **Номер карты — от ширины карты, не вьюпорта:** `.pay-stage { container-type: inline-size }` + `.pay-num { font-size: clamp(12px, 5.8cqw, 21px) }` (vw-кламп остён fallback'ом). В узкой колонке сетки (карта ~250–330px) старый `5.6vw` давал 21px и номер обрезался — cqw масштабирует гарантированно.

## [1.13.1] — 2026-09-12

### Fixed
- **Коллизия классов `.pay-card`** (демо lovii-demo): имя 3D-карты сталкивалось с карточкой шага «Платёж и возврат» онбординга МСП — карта уезжала вправо (`margin: 0 16px` от чужого правила при `width: 100%`), а та получала чужие `aspect-ratio/border/padding`. 3D-карта переименована в **`.paycard`** (без дефиса) в слое компонентов, examples/08 и каноне; в правило добавлен явный `margin: 0`.

### Changed
- **Терминология (канон владельца, 2026-09-12): «клубы» выведены из продукта.** Сокращение **LOVII CLUB (LC)** упразднено — остаётся только **LOVII PAY**. Программа привилегий: уровни **LOVII PAY** (база) → **LOVII PASS** (действующая подписка) → **LOVII VIP** (оборот по карте). Привилегии — **мерч, мероприятия, спец-скидки у МСП**; повышенный кэшбек НЕ используется (убраны «×2 кэшбек», «ставка клуба»).
- `lc-badge` → **`pay-badge`**, `club-head` → **`pay-head`**; `tier-cb` → **`tier-cond`** (условие уровня вместо ставки кэшбека); новый блок **`tier-levels`/`.tl`** — полоска уровней PAY→PASS→VIP (текущий — gold-капсула). §10, docs/09 §8, docs/12 «Группа 11», examples/08 `#clubpay` — синхронно с демо.
- Демо-номер карты: префикс **9643** по спецификации номеров карт лояльности (MII 9 + код страны 643 + код эмитента; 16 цифр, Лун): `9643 9138 4210 7755`. Держатель на карте — латиницей.
- **Спрайт v6: +1 иконка** (50→51): `i-ticket` — закрытые мероприятия.

### Terminology (канон владельца)
- Платформа — «Лови» · клуб — **LOVII CLUB (LC)** · карта — **LOVII PAY** (включает счёт и баланс). «Карты жителя» нет. Экономика клуба: 1 балл = 1 ₽, баллы не сгорают, вывод через СБП. Эталон реализации — lovii-demo `js/club.js` (тот же словарь классов).

## [1.12.0] — 2026-09-05

### Added
- **Второй артефакт сборки `lovii-tokens.css`** — слой токенов+базы+движения БЕЗ компонентов: для потребителей, ведущих свой компонентный слой. Первый случай — витрина lovii.mobiap.com (репо lovii-demo): её словарь классов разошёлся с каноном (87 общих имён, 60 правил с разной анатомией — полный lovii.css визуально ломает демо).
- **Слой A-COMPAT `tokens/compat-legacy.css`** — 31 легаси-алиас (`--pink → var(--lv-pink)`, `--bg`, `--card`…): код, выросший до канона `--lv-*`, продолжает работать и автоматически получает канонические значения, включая темные. Алиасы входят в ОБА артефакта; новые проекты алиасы не используют (правило в шапке файла). Закрыт хвост v1.3.0 («Демка — очередь разноски»): демо получает бежевый фон `--lv-bg #f8f5f0` и канонические dark-значения `--lv-gold-text/--lv-tiffany-text` — осознанные решения v1.3.0/v1.2.0.
- **Поле `src` в реестре `tools/targets.json`** — per-consumer выбор артефакта (по умолчанию `lovii.css`); `sync-lovii-css.py` и `propagate.py` читают его (провенанс и коммит-сообщение называют артефакт). lovii-demo добавлен в `consumers` (dest `assets/lovii-tokens.css`), `future` пуст.

### Migration
- lovii-demo: `index.html` подключает `assets/lovii-tokens.css` ПЕРЕД своим `css/lovii.css`; из последнего удалены блоки токенов `:root`/`[data-theme]` (значения теперь канонические через алиасы); `sw.js` CACHE → lovii-v18. Приёмка: скриншот-набор до/после `scripts/demo_migration_shots.py` (shots/lovii_demo_migration/).

## [1.11.0] — 2026-09-05

### Added
- **Фреймворк-режим: одна команда разноски `tools/propagate.py`** — правка стиля в lovii-design → `build-lovii-css.py` → снапшоты во ВСЕХ потребителей → стражи приёмки → точечные коммиты+пуши (`--push`; коммитится только файл снапшота, несвязанные изменения репо не трогаются). Режимы: `--check` (сверка), `--smoke` (playwright-приёмка), `--only`, `--no-build`.
- **Реестр потребителей `tools/targets.json`** — единственное место со списком сайтов на фреймворке ( lovii · lovii-site; lovii_demo — в `future`, после миграции витрины на LOVII UI). `sync-lovii-css.py` читает реестр (резервный встроенный список — на случай его отсутствия).
- **Живой адрес фреймворка зафиксирован**: <https://bestdeejay-design.github.io/lovii-design/> — хаб, style-guide, examples, `lovii.css` раздаётся Pages (режим «live-подключения» для будущих прототипов; прод-потребители lovii.ru/lovii-site остаются на снапшотах с провенансом).
- Предохранитель propagate: STOP, если lovii-design не закоммичен/не запушен — провенанс снапшота всегда указывает на существующий на GitHub коммит.

### Changed
- Шапка сборки lovii.css: версия токенов + дата сборки; хеш коммита теперь только в шапке снапшота (инъекция разносчиком). Устранён вечный рассинхрон «пересобрал после коммита — хеш в файле устарел».
- Репо lovii: `core.fileMode false` — файловый шум mode-битов больше не маскирует диффы снапшотов.

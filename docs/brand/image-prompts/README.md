# lovii-image-prompts

Отдельная папка со всеми найденными чатами, в которых генерировались картинки и фото
для проекта LOVII (написание встречается и как LOVII, и как «Лови»).

## Что внутри

- `01-lovii/` — чаты с генерацией картинок именно по LOVII: презентационные визуалы,
  иконка приложения, сцены партнёров, витрина на телефоне, hero с кэшбэком, логотип.
- `02-vitrina-i-sait/` — промты на изображения интерфейса/дизайна Витрины и сайта LOVII.
- `03-stili-i-eksperimenty/` — прогоны генерации в разных стилях (Малевич/Кандинский/Ван Гог,
  Disney, пиксель-арт, обложки, обои). LOVII в тексте не упоминается — положены отдельно,
  чтобы не потерялись, но и не мешали.
- В каждой папке чата: `conversation.md` (полный диалог), `conversation.json` (структурно,
  там же ссылки на сгенерированные изображения), `PROMPTS.md` (только запросы пользователя,
  пронумерованные — то, что нужно копировать).
- `INDEX.md` — таблица всех чатов с описанием, что в каком лежит.

## Картинки

Все ссылки на сгенерированные изображения из этих чатов скачаны локально:
**101 файл PNG, ~143 МБ**. Лежат локально в `<папка чата>/images/` (в git не входят —
см. `.gitignore`; в репозитории остаются `IMAGES.md` со ссылками), нумерация — порядок
появления в диалоге. В каждой папке чата `IMAGES.md` — таблица «файл → промт →
ссылка» (по ней видно, какая картинка на какой запрос).

Пять ссылок скачать не удалось — они сохранены в экспорте без подписи (`?key=...`),
CDN отдаёт `404`:
- `03-stili-i-eksperimenty/iPhone Background Design` — 2 из 3
- `03-stili-i-eksperimenty/Диджей и неоновая атмосфера` — 3 из 3

Остальные открываются; копии теперь локальные, так что от срока жизни ссылок не зависят.

## Как это собрано

Архивы переписок: приватные репозитории `bestdeejay-design/qwen-chats` и
`bestdeejay-design/deepseek-chats` (полные), плюс тематические выборки `chats`,
`chats-audit`, `chats-job` — в них те же чаты с префиксами. Всего 460 уникальных чатов,
из них с генерацией изображений — 38. Сюда отобраны те, что про LOVII, дизайн Витрины
и эксперименты со стилями.

Отбор: наличие вывода-изображения (ссылки `cdn.qwenlm.ai/.../t2i/...`) и/или промтов
на генерацию, затем ручная проверка каждого чата по первым запросам.

Ссылки на сами картинки внутри `conversation.md` — это CDN Qwen с подписанными ключами;
со временем они могут перестать открываться. Сами файлы изображений в архивах не лежали.

## Чего здесь нет

- Схемы партнёрской сети и бизнес-чаты, где изображения были побочным результатом
  (`Анализ Схемы Партнерской Сети`, `Стартап Реклама и Недвижимость`) — это диаграммы, не картинки.
- Музыкальные и текстовые чаты.

# Changelog

Все значимые изменения дизайн-системы LOVII. Формат — Keep a Changelog, версионирование — SemVer.
Изменение значений токенов: backward-compatible — MINOR, ломающее — MAJOR, правки правил/опечаток — PATCH.

## [1.1.0] — 2026-09-04

### Added
- **Новые токены** `--lv-on-tile` / `--lv-on-tile-dim` / `--lv-tile-chip` (обнаружено при сборке референсов: плитки фиксированно светлые, их текст не должен браться из темовых ink/dim — в тёмной теме он растворяется).
- **Библиотека паттернов** `docs/07-patterns.md`: 13 разделов copy-paste сниппетов (тема и anti-FOUC, каркас, хедер, кнопки, пилюли/бейджи, карточки, формы, сегменты, bottom-sheet, toast, пустое состояние, навигация) + таблица антипаттернов «симптом → причина → как надо».
- **Рецепты для агента** `docs/08-recipes.md`: 8 типовых процедур (Р1 сборка экрана, Р2 компонент, Р3 токен, Р4 подключение ДС в новый репозиторий, Р5 приёмка с grep-командами, Р6 перенос из легаси, Р7 визуальный баг, Р8 обновление style-guide) + карта «роль → референс».
- **Референс-экраны по ролям** `examples/`: 01-client-store (клиент: витрина с bottom-nav, тостами, лентами), 02-business-dashboard (бизнес: KPI, сегменты, гистограмма, статусы заказов), 03-partner-portal (партнёр: статус на gradient-ink, реферальная ссылка, выплаты), 04-ambassador-program (амбассадор: промокод градиентным текстом, уровни, чек-лист), 05-investor-overview (инвестор: метрики, таймлайн-роадмап, команда). Все — на `../tokens/tokens.css`, обе темы, anti-FOUC, канонические каркасы 480/1120/760px.
- **SKILL.md v2**: карта ролей → референсы, критичные сниппеты (anti-FOUC, applyTheme, логотипы) прямо в скилле, ссылки на 07/08/examples, расширенная процедура работы.

### Changed
- `AGENTS.md`: порядок работы агента дополнен шагами (роль → пример → сниппеты → рецепты), обновлён раздел «что читать дальше».
- `README.md`: состав репозитория и roadmap (v1.1 готова, расхождения перенесены на v1.2).

## [1.0.0] — 2026-09-04

### Added
- Токены: `tokens/tokens.css` (канонические CSS-переменные `--lv-*`, обе темы, анимации, базовые стили) и `tokens/design-tokens.json` (машиночитаемая версия, упрощённый W3C Design Tokens).
- Документация: принципы (01), цвет (02), типографика (03), пространство/форма/движение (04), контракт тем (05), применение в репозиториях + таблица расхождений (06), чек-лист приёмки (checklist).
- Живой style-guide: `style-guide.html` — самодостаточная страница с обеими темами (сборка `tools/build-style-guide.py`; логотипы и токены инлайнятся из канона).
- Канон-ассеты: `assets/lovii-logo-light.svg`, `assets/lovii-logo-dark.svg` (md5 `145731d888e5d913ce85de3a9789d097`, идентичен `lovii-logo-black.svg`).
- Правила для ИИ-агентов: `AGENTS.md` (карта репозиториев, железные правила, порядок работы) и заготовка скила `SKILL.md`.

### Fixed
- Синхронизация логотипа тёмной темы с каноном lovii.mobiap.com (высветленный `lovii-logo-dark.svg` удалён из демки в коммите 38dc7b1 lovii_demo, логотип lovii-site откачен к канону в 6b62bf9 lovii-site; зафиксировано в docs/05 и docs/06).

### Known divergences
- Зафиксированы в docs/06-application.md: dark-альфы soft-токенов (канон .12/.12/.16 vs lovii-site .20/.18/.20), dark-тени soft/lift, mist-pink. Статус: ⚠ требует решения (v1.1).

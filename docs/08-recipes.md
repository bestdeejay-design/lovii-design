## Р1. Собрать новый экран с нуля

1. Определи роль и открой её референс из таблицы выше — копируй каркас оттуда.
2. Собери `<head>` по сниппету «Тема» из `docs/07-patterns.md` §1 (порядок: anti-FOUC → шрифт → tokens.css → meta).
3. Выбери каркас: капсула 480px (клиент) / wide 1120px (бизнес) / narrow 760px (линейные роли).
4. Собери секции из паттернов §2–§12. Каждый компонент бери готовым сниппетом, не придумывай новые значения.
5. Проверь: обе темы, 375px без гориз. скролла, фокус с клавиатуры.
6. Прогони `docs/checklist.md` (все разделы).
7. Зафиксируй: если появилось новое значение — сначала Р3 (токен), потом использование.

**Критерий готовности:** экран неотличим по стилю от референса при переключении тем, чек-лист пройден полностью.

## Р2. Добавить новый компонент

1. Проверь, что компонента нет: `docs/07-patterns.md`, `style-guide.html`, `examples/`.
2. Собери его из существующих токенов (значение уже есть почти всегда).
3. Опиши сниппет в `docs/07-patterns.md` (HTML+CSS, Do/Don't).
4. Добавь живую версию в `tools/` шаблоны style-guide → пересобери (`python3 tools/build-style-guide.py`).
5. Пример использования — в подходящий `examples/*.html`.
6. CHANGELOG: MINOR (новый компонент).

## Р3. Добавить новый токен

1. Убедись, что значения действительно нет: grep по `tokens/tokens.css`.
2. Придумай имя `--lv-*` по аналогии с существующими (тема/поверхность/текст/тень).
3. Внеси в `tokens/tokens.css` (обе темы, если темовый) **и** в `tokens/design-tokens.json`.
4. Если это пара (заливка + текст) — внеси оба и сразу задокументируй пару.
5. Пересобери style-guide, добавь в docs/02–04 (раздел по типу токена).
6. Только теперь используй в коде. CHANGELOG: MINOR/PATCH.

⚠️ Токены light и dark меняются синхронно: добавил в `:root` — проверь, что dark-версия осмысленна (или явно наследуется).

## Р4. Подключить дизайн-систему в новый репозиторий

1. Скопируй в проект: `tokens/tokens.css`, `assets/lovii-logo-{light,dark}.svg`.
2. `<head>` — по сниппету §1 docs/07 (anti-FOUC до CSS — обязательно).
3. Базовые стили из tokens.css подключаются автоматически (body, focus-visible, reduce-motion).
4. Tailwind-проект (как lovii-site): пробрось `--lv-*` в `@theme inline` как `--color-lovii-*`; классы `bg-lovii-pink` и т.п. — смотри маппинг в `docs/06-application.md`.
5. Логотип: оба файла в DOM, видимость через CSS (сниппет §1).
6. Проверь холодный старт обеих тем + системную тему.

**Анти-паттерн:** копировать значения из tokens.css в свой css-файл. Только `<link>` на токены или их прямой импорт.

## Р5. Приёмка готовой вёрстки

1. Открой `docs/checklist.md` — пройди все 10 разделов.
2. Автоматические проверки:

```bash
# Хардкод цветов вне токенов (ожидаемы только канон-литералы: #999, badge-подложки)
grep -rn "#[0-9a-fA-F]\{3,8\}" --include="*.css" --include="*.html" путь/к/экранам | grep -v tokens.css

# Тема не на body
grep -rn "body\[data-theme" путь/к/проекту   # должно быть пусто

# Инверсия запрещена
grep -rn "filter:\s*invert" путь/к/проекту   # должно быть пусто

# Кэш демки (если менялась статика): ?v=N в index.html и CACHE lovii-vN в sw.js
```

3. Визуально: обе темы, 375px и десктоп, холодный старт, скриншоты рядом с `style-guide.html`.
4. Зафиксируй результат в отчёте задачи (что проверено, что отклонено).

## Р6. Перенести стиль из легаси на токены

1. Найди значение в легаси-файле (`css/lovii.css` демки, `globals.css` site).
2. Найди каноническое имя по маппингу в `docs/06-application.md`.
3. Замени использование на `var(--lv-*)` / Tailwind-класс `bg-lovii-*`.
4. Не удаляй легаси-переменную, пока не убраны все использования (grep).
5. Демка: подними `?v=N` и `CACHE lovii-vN` (см. AGENTS.md §2.8).
6. Проверь визуально обе темы.

## Р7. Исправить визуальный баг

1. Воспроизведи локально (обе темы, нужный вьюпорт). Сфотографируй до/после.
2. Определи уровень проблемы:
   - **неверное значение** → правь реализацию (значение уже есть в токенах);
   - **нет подходящего токена** → сначала Р3;
   - **баг дизайн-системы** (токен сам по себе неверен) → правка токена в lovii-design → разнос по иерархии lovii_demo → lovii-site.
3. Проверь, что фикс не сломал второй режим: тёмную тему, другой вьюпорт.
4. Запиши в CHANGELOG lovii-design, если менялся токен/правило.

Помни кейс style-guide: `.gs-header img.gs-logo` (0,2,1) перебивал `img.logo-dark-img`. При «призрачных» элементах первым делом проверь специфичность селекторов.

## Р8. Обновить style-guide

1. Правки только через `tools/build-style-guide.py` + шаблоны `tpl-*.part.html` — не редактировать `style-guide.html` руками (он генерируется и будет перезаписан).
2. Запусти страж центра правды: `python3 tools/check-sync.py` — 0 ошибок (значения токенов не копируются в шаблоны, AGENTS пр.13).
3. После сборки: открой в браузере, переключи тему, прогони интерактив (sheet — Escape/оверлей, toast), сверй таблицу свотчей с фактическим фоном страницы.
4. Мобильный 375px: нет гориз. скролла, хедер без дубля-логотипа.
5. Коммит: `feat|fix(style-guide): …`, CHANGELOG PATCH.
